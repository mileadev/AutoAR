## Required acceptance tests (not completed in this environment)

1. `go test ./...`, `go vet ./...`, and the GoSec CI job must pass.
2. `docker build --pull -t autoar:review .` must succeed without access to the host Docker socket; confirm the effective runtime UID is non-root.
3. `docker compose config` must pass; a network-accessible unauthenticated API must refuse startup.
4. Verify an Ollama local model and a direct Ollama Cloud model with non-sensitive fixtures and model provider keys stored outside the repository.
5. Run an **approved target only** test for `AUTOAR_AI_ALLOWED_DOMAINS`, including rejected out-of-scope hostname, shell action, arbitrary flags, IP addresses, and empty scope.
6. Audit imported frontend JavaScript and externally downloaded wordlists/Nuclei templates. Hash pinning is not malware validation.
7. Review secret material at rest (database, backups, environment files), outbound egress allowlists, SSRF constraints, and API rate limits. Validate R2 bucket access controls.

## Operational guardrails

- Do not run as host root and do not mount the Docker socket.
- Never turn on AI execution without a restricted domain allowlist, a dedicated scanner user, and independently enforced egress restrictions.
- R2 and hosted LLM endpoints may receive sensitive scan results when enabled; require authorization before sending data to external services.
- Treat reports generated by an LLM as hypotheses until verified from raw evidence.
- Require CI and manual review before merging PR #2. GitHub Actions has reported zero runs for this repository during the review; do not interpret absent checks as passing.

## Evidence limitations

This is a source-grounded remediation register, **not** a malware-free attestation. Full local builds and runtime tests were unavailable because container network access could not reach GitHub and local Go is older than the module's requirement. No deployed system was scanned or modified. Validate third-party code provenance and actual builds in a controlled, network-enabled CI environment.
